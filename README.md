# my_obsidian

Vault untuk semua project dan catatan kerja.

## Struktur
- `00-Inbox/` — catatan cepat yang belum diproses
- `10-Projects/` — satu folder per project aktif (`<Klien>-<Topik>`)
- `20-Areas/` — tanggung jawab berkelanjutan (karier, studi, keuangan)
- `30-Resources/` — referensi lintas project (framework, regulasi, teknologi)
- `40-Archive/` — project yang sudah selesai
- `90-Templates/` — template catatan
- `99-Attachments/` — gambar dan lampiran umum

## Struktur folder project
- `00-Admin/` — TOR, kontrak, timeline, kontak
- `01-Sources/` — dokumen dari klien (jangan commit dokumen rahasia)
- `02-Analysis/` — analisis kerja
- `03-Deliverables/` — draf laporan
- `04-Meetings/` — notulen rapat
- `05-Research/` — riset publik
